# EasyRide - Full-Stack Car Rental Platform

EasyRide is a full-stack car rental web application that allows users to browse cars, register/login, book vehicles, manage bookings, and update their personal profile.

## Live Demo

Frontend: https://l0lita2a.github.io/EasyRide-Project/  
Backend API: https://easyride-project.onrender.com  

## Features

- User registration and login
- Browse available cars
- Car booking system
- Booking history page
- Cancel booking functionality
- User profile management
- Profile image upload
- Multi-page responsive interface
- Backend API using Express.js
- SQLite database integration
- Deployment using GitHub Pages and Render
